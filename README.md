# ling-ai-tools

小机凌的开源 AI 工具箱 · skill、agent、规则模板，AI 协作实战沉淀的实用小工具

## 这是什么

我是小机凌，8 年产品经理，现在用 AI 干掉重复工作。这个仓库放我在实际工作中用 AI 协作时沉淀的小工具——单个能用，不绑定任何框架。

每个工具都是我自己在用、跑通过、验证过有效才放上来。不是理论，是实战沉淀。

## 适合谁用

- 在用 AI 编程工具（opencode、Cursor、Claude Code 等）的人
- 想让 AI 帮你干活，但又怕 AI 改出问题没人兜底的人
- 想搭建自己的 AI 工作流，需要参考别人怎么做的的人

## 怎么用

每个工具目录下都有独立的 README，说明这个工具干什么、怎么装、怎么用。直接点进对应目录看就行。

每个工具目录里还有一份《给AI助手的说明.md》——你是让 AI 助手（WorkBuddy / opencode / Claude Code 等）帮你装的话，让它读这份说明，它就能直接替你把环境和内容配好，不用你一步步指挥。

工具之间互相独立，你可以只拿你需要的那个，不需要装全套。

# 给AI助手的说明（安装指引）

> **目标读者**：AI 助手（WorkBuddy / opencode / Claude Code / Cursor 等皆可）。
> 用户刚下载这个目录，会对你说：「按这个目录里的说明帮我装好」。你读完本说明直接执行，不需要用户指挥。

---

## 你要帮忙达成的事

让用户在自己电脑上跑通「HTML 图卡一键导出高清 PNG」，并能做出她自己内容的小红书/抖音图文。

## 前置检查（必做）

1. 确认目录有三样：`demo.html`、`lib/html-to-image.min.js`（约19KB）、`README.md`
2. `demo.html` 和 `lib/` 必须**同一个目录**（HTML 里是相对路径引用 `lib/html-to-image.min.js`），分开会导致按钮点击没反应
3. 细节（核心代码/参数/踩坑记录）看同目录 `README.md`

## 安装与验证（一次跑通就算装好）

1. 让用户用 **Chrome** 打开 `demo.html`
2. 点右上角紫色按钮「**导出全部图片**」
3. **预期结果**：浏览器自动下载 2 张 PNG（`图文_第1张.png`、`图文_第2张.png`，尺寸 2160×2880 高清），最后弹窗提示
4. 按钮点了没反应？大概率是库没加载成功——检查 HTML 里 html-to-image 的引用是否为**本地相对路径**（CDN 引用会被浏览器跟踪防护拦截，这是最大的坑）
5. 导出正常 → 环境没问题，进入下一步

## 帮用户做她自己的图卡

1. 参照 `demo.html` 的结构另建一个 HTML（或直接改 demo），把 `.page` div 里的占位内容换成用户的内容
2. **一页就是一张图**：`.page` 固定尺寸 1080×1440px（小红书 3:4）；抖音竖版图改成 1080×1920
3. 想放几张图就写几个 `.page`，导出按钮会自动循环全部，不用拆多个文件
4. 文字量建议：每张图可见文字 ≤50 字（社交平台上用户是扫不是读，核心信息做大字）
5. 图里要嵌照片时：把图片文件放同目录，HTML 里用文件名引用：`<img src="xxx.png" onerror="this.style.display='none'">`
6. 导出按钮脚本不用动（只有完成弹窗里的张数 `alert('2张图片下载完成！')` 按实际 page 数改）

## 完成标准

demo 验证通过 + 用户自己的图卡 HTML 能导出她的内容 + 用户知道下次怎么打开用。最后告诉用户：每次只需要改 `.page` 里的内容，点按钮导出，图直接传小红书/抖音。
